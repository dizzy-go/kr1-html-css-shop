## Тёмная тема

Тёмная тема реализована двумя способами:

1. Автоматически — через `@media (prefers-color-scheme: dark)`.
   Если у пользователя в системе включена тёмная схема, сайт автоматически
   переключается на тёмное оформление.
2. Вручную — через кнопку «Тёмная тема» в шапке сайта.
   Выбор пользователя сохраняется в `localStorage` и применяется на всех
   страницах проекта при последующих визитах.

Переключение цветов выполняется через атрибут `data-theme` на элементе `<html>`
и переопределение CSS-переменных в блоках `[data-theme="dark"]` и
`:root:not([data-theme="light"])`.
